# Activer la compression des réponses HTTP

## Comment tester

Requêter `/` et `/admin/login` avec `Accept-Encoding: gzip`, puis vérifier l'en-tête `Content-Encoding`.

Cas à ne pas sonder : `https://other.example.net/page`, `/produit/<slug>` et `/etc/nginx/nginx.conf`.

Point de santé : `https://preprod.example.org/api/status`.
